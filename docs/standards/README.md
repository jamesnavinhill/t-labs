# Agency Standards

This directory is the durable operating canon for Agency. Read the standard
that owns the work before creating parallel rules elsewhere.

- Documentation: durable technical and operating documentation.
- Tooling: official tools, contracts, and source-of-truth boundaries.
- Planning: implementation plans and retirement rules.
- Reports: feasibility and research reports.
- Development cycle: local automation, Docker, CI, and verification.
- Repository layout: durable homes for source, configuration, records, and
  transient output.

Top-level agent guidance points here rather than duplicating these rules.
